接口

    GET  /rpc/token
    GET  /rpc/getTodos
    POST /rpc/addTodo
    POST /rpc/toggleTodo
    POST /rpc/deleteTodo
    POST /rpc/updateTodo
    WS   /ws

Token

1. 前端 GET /rpc/token
2. 后端生成 token，存数据库
3. 前端存内存
4. 每次请求带 X-Token
5. 后端查库校验

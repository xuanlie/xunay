# 后端目录说明

本仓库有两套"后端"目录，容易混淆：

## backend/（单数）

**正在运行的 FastAPI 应用**。这是实际提供服务的代码，由当前 `xunay.config.json` 的 `backend` 字段决定是否需要它。

- `main.py` — FastAPI 入口
- `api/todos.py`、`api/token.py`、`api/ws.py` — 路由
- `core/security.py`、`core/errors.py` — 认证与错误处理
- `db.py` — SQLite 连接
- `schemas.py` — Pydantic 模型
- `static.py` — 静态文件托管
- `data.db` — 运行时数据库（**不提交**，已 gitignore）

启动：`bash scripts/run-backend.sh` 或 `python -m uvicorn backend.main:app --port 12342`

## backends/（复数）

**四语言后端模板库**，是"用 xunay 起一个后端"的参考实现，不是运行代码。

- `backends/node/` — 零依赖 Node 实现
- `backends/python/` — FastAPI 精简版
- `backends/go/` — Go 标准库
- `backends/cpp/` — httplib + CMake

每个目录结构平行，都实现 `shared/routes.json` 里的同一套路由。

## 关系

`backends/` 是模板，`backend/` 是当前项目在跑的那个实例。二者不同名、不同结构，**不是重复代码**。

路由一致性由 `node bin/check-routes.js` 校验——它读 `shared/routes.json`，检查四个模板是否都实现了。

示例

XuNay 自带 5 个示例，从简单到完整。

计数器

最简单的例子。看 examples/counter/index.html。

要点：

  一个 signal
  一个 mount
  两个按钮

Todo（简单）

examples/todo/index.html。

支持添加、勾选、删除。

1000 行列表

examples/list-1000/index.html。

演示 list 的精确更新：

  1000 行首次渲染 < 50ms
  更新一行 < 5ms
  替换全部 < 50ms

生命周期

examples/life/index.html。

演示 onMount / onUnmount。

完整 Todo（推荐看）

examples/full-todo.xuy。

完整功能：

  添加 / 删除 / 勾选
  筛选：全部 / 未完成 / 已完成
  双击编辑
  计数统计
  清除已完成
  删除全部
  localStorage 持久化

用它演示 .xuy 构建流程：

    node bin/xuyc.js build examples/full-todo.xuy --out dist/todo

输出在 dist/todo/，直接部署。

运行示例

传统方式（直接写 index.html）

    cd examples/counter
    python3 -m http.server 8080

浏览器打开 http://localhost:8080。

.xuy 方式（推荐）

    node bin/xuyc.js build examples/full-todo.xuy --out dist/todo
    cd dist/todo
    python3 -m http.server 8080

构建工具 xuyc

XuNay 自带构建工具。只写 .xuy，一键出成品，不用写 index.html，不用配 webpack/vite。

用法

    node bin/xuyc.js build <入口.xuy> [--out 输出目录]

例子：

    node bin/xuyc.js build examples/full-todo.xuy --out dist/todo

输出：

    dist/todo/
    ├── index.html     自动生成的 HTML
    ├── app.js         打包后的应用（esbuild）
    └── xunay.js       XuNay 运行时（ESM 版）

丢到任何静态服务器就能跑。

写 .xuy

.xuy 就是 JS，只是约定用 XuNay 的 API：

    // title: 我的应用
    import { div, span, signal, mount } from 'xunay'

    const n = signal(0)

    mount(() => div(null,
      span(null, () => n = ${n()})
    ), '#app')

第一行 // title: xxx 会作为 <title> 写进 index.html。

打包过程

1. 读 .xuy 源文件
2. 把 from 'xunay' 替换成 from './xunay.js'
3. 复制 core/dist/xunay.esm.js 到输出目录
4. 用 esbuild 把 .xuy 打包成 app.js（bundle + minify + ESM）
5. 生成 index.html

本地预览

    cd dist/todo
    python3 -m http.server 8080

浏览器打开 http://localhost:8080。

为什么不用 Vite / Webpack

  XuNay 不需要 JSX 编译（直接写 div(...)）
  XuNay 不需要热更新（Signal 更新很快）
  XuNay 不需要复杂配置（一个命令搞定）

只需要一个能打包 ESM 的工具，esbuild 够了。

npm 脚本

在 package.json 里加：

    {
      "scripts": {
        "build": "node core/build.js",
        "xuyc": "node bin/xuyc.js"
      }
    }

然后：

    npm run build                 # 打包 XuNay 运行时
    npm run xuyc build app.xuy    # 构建应用

完整流程

    # 1. 构建 XuNay 运行时（只做一次）
    node core/build.js

    # 2. 写你的 .xuy 文件
    vim myapp.xuy

    # 3. 构建
    node bin/xuyc.js build myapp.xuy --out dist

    # 4. 部署
    # dist/ 里三个文件丢 CDN
